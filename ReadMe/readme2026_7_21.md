# 💎 Functions & Concepts & Core Snippets

## 1. Shared Resource Problem

多个线程访问同一个变量：

```cpp
_count++;
```

实际执行：

```
Read
Modify
Write
```

多个线程同时修改会产生：

```
Race Condition
数据竞争
```

---

# 2. Mutex

Mutex:

```
Mutual Exclusion
```

作用：

保证同一时间只有一个线程进入临界区。

流程：

```
Lock

Critical Section

Unlock
```

---

# 3. Thread Safe Counter

共享变量：

```
_count
```

保护：

```cpp
Lock();

_count++;

Unlock();
```

最终保证：

```
count = expected value
```

---

# 4. Lock Granularity

错误：

```cpp
for(...)
{
    Lock();
    count++;
    Unlock();
}
```

问题：

- 锁操作频繁
- 性能下降


优化：

```cpp
Lock();

for(...)
{
    count++;
}

Unlock();
```

---

# 5. Deadlock

死锁：

多个线程互相等待资源。


四个条件：

1. Mutual Exclusion
2. Hold and Wait
3. No Preemption
4. Circular Wait


实验：

Thread1:

```
Lock(A)

Lock(B)
```


Thread2:

```
Lock(B)

Lock(A)
```


结果：

```
Thread1 等待 B

Thread2 等待 A
```

程序阻塞。

# 🐛 Mistakes & Debugging Loops


## Deadlock没有出现

原因：

锁竞争没有发生在线程内部。

正确：

```
Thread1:
A -> B

Thread2:
B -> A
```


---

## Segment Fault

原因：

线程访问已经失效对象。


解决：

使用：

```cpp
this
```

传递对象地址。


---

# Deadlock Avoidance

统一锁顺序：

错误：

```
Thread1:
A -> B

Thread2:
B -> A
```


正确：

```
Thread1:
A -> B

Thread2:
A -> B
```

避免循环等待。
