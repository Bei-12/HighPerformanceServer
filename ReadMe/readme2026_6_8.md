## 🍫 Functions & Concepts & Core Snippets
### 1.Functions: 
      (1) Process Control:
          fork() -- creates a child process.Return value: the parent process gets the child process's PID, and the child process gets 0
          exit() -- terminates the current process and release user-space resources
          waitpid() -- waits for the specified child process to teminate, reclaims its resources, and prevents aombie processes
      (2) Pipe Communication:
          pipe() -- Creates an anonymous pipe, pipe[0] for reading and pipe[1] for wriring
          read() -- Reads data from a file descriptor and returns the number of bytes read; 0 indicates the write end is closed
          write() -- Writes data to a file descripor and returns the number of bytes written
          close() -- Closes the file descriptor to prevent resource leaks
      (3) Memory Management:
          malloc() -- Allocates the specified number of bytes of memory on the heap, returning 'void*' or 'NULL' on failure
          free() -- Frees the memory allocated by 'malloc'. Note that only the raw heap address can be passed as an argument
          memset() -- Fills a memory block with the specified value; commonly used for initialization and zeroing
      (4) String Manipulation
          strtok() -- Splits a string according to an delimiter and returns a pointer to the original string
          stoi() -- Converts a string to an integer; its range is limited. Use 'stoll()' for large numbers
          stoll() -- Converts a string to a 'long long'; suitable for large number conversions
          sprintf() -- Formats and writes a string; no bounds checking
          snprintf() --Formats and writes a string; it has a length limit and is safer
          strcpy() -- Copies a string; ensure the destination buffer is large enouge
          strcat() -- Concatenates strings; be aware of the risk of buffer overflow
          perror() -- Prints the error message of a system call; use in conjunctin with 'errno'
### 2.Concepts:
      (1) Process Pool:
          Definitin: Pre-creates several child processes; the parent process distributes tasks, avoiding the overhead of frequent forks
          Compodition: Parent process(task distribution) + child process pool(task execution) + pipes(communicatin)
          Scheduling: Round Robin; the index loops to point to the next worker
      (2) Anonymous pipes:
          Features: Unidirectional communicaion, can only be used between related processes
          Direction: Two pipes are created when bidirectional communciation is needed
          pipefd1: Parent -> Child(transfer task)
          pipefd2: Child -> Parent(return result)
          Key: Unused ends must be closed promptly, otherwise read operations will be blocked indefinitely
      (3) Parent-Child Process Communciation Protocol:
          Parsing Method: strtok() splitting followed by stoi()/stoll() conversion
          Data Formate: "type|number" Parent -> Child
          Return Formate: "type|result" Child -> Parent
          Separator: '|'
          Parsing Method: strtok() splitting followed by stoi()/stoll() conversion
      (4) Process Synchronization:
          Parent Process: Write task -> Read result -> Display
          Child Process: Read task -> Calculate -> Write result
          Exit Signal: Parent process sends "-1|-1", child process exits(0) upon receiving it
          Reclaim: Parent process waits for all child processes to terminate using waitpid()
### 3.Core Snippets:
      (1) Create a bidirectional pipeline:
          int pipefd1[2], pipefd2[2];
          pipe(pipefd1);  // 父→子
          pipe(pipefd2);  // 子→父
          pid_t id = fork();
          if (id == 0)  // 子进程
          {
            close(pipefd1[1]);  // 关闭写端
            close(pipefd2[0]);  // 关闭读端
            // 用 pipefd1[0] 读，pipefd2[1] 写
          }
          else          // 父进程
          {
            close(pipefd1[0]);  // 关闭读端
            close(pipefd2[1]);  // 关闭写端
            // 用 pipefd1[1] 写，pipefd2[0] 读
          }
      (2) String serialization transmission:
          // 发送端：拼接 "type|number"
          char buf[SIZE] = {0};
          snprintf(buf, SIZE, "%d|%d", type, number);
          write(fd, buf, SIZE);
          // 接收端：解析
          char *tok = strtok(buf, "|");
          int type = stoi(tok);
          tok = strtok(NULL, "|");
          int number = stoi(tok);
      (3) Safe read pipe:
          char buf[SIZE] = {0};
          int rd = read(readfd, buf, SIZE);
          if (rd == 0)       // 写端关闭，正常退出
          {
            close(readfd);
            exit(0);
          }
          else if (rd < 0)   // 读取出错
          {
            perror("read");
            exit(1);
          }
      (4) Safe cin reading:
          cin >> type;
          if (!cin)
          {
            cin.clear();
            cin.ignore(1024, '\n');
            continue;
          }
      (5) Exit and reclaim child processes:
          // 父进程通知所有子进程退出
          for (auto v : vW)
          {
            write(v._pipe_write_fd, "-1|-1", 6);
            close(v._pipe_read_fd);
            close(v._pipe_write_fd);
          }

## 🐦 Mistakes & Debugging Lops
### 1.Mistakes:
      (1) The creation order of fork and pipe is incorrect, this prevents the parent and child processes from cummuniciating through the same pipe --- Create the pipe first, then create the child process
      (2) strtok uses an infinite loop --- Using it only once
      (3) Unallocated space for char* privents data from being written
### 2.Debugging Lops:
      (1) Resource leak loop: The child processes malloc 'Type' in each loop, but after the pointer is overwritten by 'strtok', the original heap address is neither properly freed, and this memory is leaked. This leakage occurs in every task loop
