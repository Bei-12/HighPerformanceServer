TCP网络编程学习笔记

一、TCP概述

TCP（Transmission Control Protocol）是面向连接、可靠的传输层协议。

TCP特点：

面向连接

可靠传输

保证数据顺序

保证数据完整性

基于字节流

UDP特点：

无连接

不保证可靠

数据报形式

开销小、速度快

二、UDP与TCP区别

对比       UDP               TCP

连接       无连接            面向连接可靠性     不保证            保证数据形式   数据报            字节流顺序       不保证            保证接口       sendto/recvfrom   send/recv

三、TCP服务器流程

TCP Server:

socket()
   |
bind()
   |
listen()
   |
accept()
   |
recv/send

socket()

创建TCP socket：

socket(AF_INET, SOCK_STREAM, 0);

其中：

SOCK_STREAM：TCP

SOCK_DGRAM：UDP

bind()

绑定服务器IP和端口：

bind(sockfd,
     (sockaddr*)&server,
     sizeof(server));

作用：

告诉操作系统该socket负责哪个地址。

listen()

进入监听状态：

listen(sockfd, 5);

listen只需要调用一次。

accept()

accept作用：

接收客户端连接请求

获取客户端地址

创建新的通信socket

返回：

clientfd

八、TCP代码问题总结

1. listen不能循环调用

错误：

while(true)
{
    listen();
}

正确：

listen(sockfd,5);

2. Client必须先connect

错误：

send()
connect()

正确：

connect()
send()
recv()

3. recv返回值

recv返回：

返回值   含义

>0      收到数据=0       对方关闭连接<0      错误

九、TCP没有消息边界

TCP是字节流。

例如：

send("hello");
send("world");

服务器可能收到：

helloworld

也可能：

hello
world

所以实际项目需要设计协议。
