# 阶段5：非阻塞IO + epoll 多客户端TCP服务器实现总结

## 一、阶段5目标
前面的TCP服务器采用线程处理客户端，一个客户端对应一个执行流。
问题：
-   客户端数量增加，需要创建大量线程。
-   某个客户端阻塞会占用资源。
-   线程切换存在开销。

阶段5目标：
> 使用epoll监听多个文件描述符，通过事件驱动处理客户端。
核心思想：
    epoll等待事件
            |
            v
    得到发生事件的fd
            |
            v
    处理一次
            |
            v
    继续等待
一个客户端不能阻塞整个服务器。

# 三、非阻塞IO

## 为什么使用非阻塞？
阻塞IO：
    recv()
    没有数据
    一直等待
会导致服务器无法处理其他连接。

非阻塞：
    recv()
    有数据 -> 返回数据
    没有数据 -> EAGAIN
EAGAIN不是错误，而是：

> 当前没有数据，可以处理其他事件。

------------------------------------------------------------------------

# 四、epoll流程

## 1. 创建epoll
``` cpp
epoll_create()
```
创建事件管理对象。

## 2. 添加fd
``` cpp
epoll_ctl()
```
监听：
-   EPOLLIN：可读事件
-   EPOLLOUT：可写事件

## 3. 等待事件
``` cpp
epoll_wait()
```
返回已经就绪的fd。

# 七、业务处理理解

业务处理：
不是网络操作。
它表示：
> 根据收到的数据生成需要返回给客户端的数据。

例如：
客户端：
    hello
业务：
    Server received --- hello

真实服务器中可能是：
-   查询数据库
-   用户登录验证
-   文件读取
-   RPC调用
-   数据计算

------------------------------------------------------------------------

# 八、EPOLLOUT理解

send并不一定成功。
如果发送缓冲区满：
    send()
    返回EAGAIN

因此需要：
1.  保存没有发送的数据
2.  等待EPOLLOUT

EPOLLOUT表示：
> 当前socket发送缓冲区可以写。

------------------------------------------------------------------------

# 九、事件状态转换

    EPOLLIN

            |
    EPOLLIN + EPOLLOUT
            |

# 十、开发过程中遇到的问题

------------------------------------------------------------------------

## 问题2：EAGAIN理解错误
非阻塞模式：

EAGAIN表示：
> 当前没有数据，不需要阻塞等待。

处理：返回epoll_wait继续等待。

------------------------------------------------------------------------

## 问题3：为什么recv循环读取？
一次recv不能保证读取完整数据。

例如：
    发送10000字节
    一次recv只能读取4096

所以：
    循环recv
    直到EAGAIN

------------------------------------------------------------------------

## 问题4：EPOLLOUT如何打开？
不是send触发。

流程：

    发现有数据需要发送
            |
    epoll_ctl MOD
            |
    监听EPOLLOUT
            |
    epoll_wait返回

------------------------------------------------------------------------

## 问题5：Add成功后fd被关闭
错误：
``` cpp
if(!epoller_.Add(fd)!=0)
```

由于运算优先级错误，会导致Add成功后关闭fd。

正确：
``` cpp
if(epoller_.Add(fd)!=0)
{
    close(fd);
}
```

------------------------------------------------------------------------

## 问题6：Business调用位置错误
错误：先判断output_buffer。

但是Business负责生成output_buffer。

正确：

    input_buffer有数据
            |
    Business()
            |
    output_buffer产生数据
            |
    开启EPOLLOUT
