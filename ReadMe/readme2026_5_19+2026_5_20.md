## ⭐ Core Concepts & Code Snippets

### 1.UnamedPipe Creation Principle & Functions
- `pipe()`: Create a new pipe, using array pipefd to control file read-write atrribute. Return `-1` as mistake message. 

### 2.Fork Creation Principle & Functions
- `fork()`: Create a new progress(child progress). return `0` shows child progress is executing its codes. return `-1` as the fail message. return `!0` shows father progress is executing its codes.

### 3.Open & Close & Functions
- `close()`: Through fd to close the read of the pipe and write of the pipe,pointing to anonymous pipe

### 4.Pass on & Functions
- `read()`: Through fd read data from anonymous pipes 
- `write()`:Through fd read data to anonymous pipes
