## 🧠 Core Concepts & Code Snippets

### 1. Thread Creation & Identity
- `pthread_create()`: Creates a new thread. Pass `NULL` for default attributes.
  - *Note:* Function pthread_create's parameter must match `void* func(void*)`. Use `NULL` if no arguments are passed.
- `pthread_self()`: Returns the unique Thread ID (TID) of the calling thread. 
- `pthread_equal()`: Compares two thread IDs to see if they refer to the same thread.
  - *Why needed:* Because `pthread_t` is an opaque data type in Linux (can be a structure or unsigned long), you **cannot** use the standard `==` operator. Explicitly calling `pthread_equal()` is required for cross-platform compatibility.

### 2. Thread Lifetime Control
- `pthread_join()`: Suspends the calling thread until the target thread terminates. Used to reclaim resources and prevent "zombie threads".
- `pthread_detach()`: Detaches the thread so its resources are automatically released upon termination.

## 🛠️ Mistakes & Debugging Logs

### Bug 1: Undefined reference to 'pthread_create'
- **Cause:** Linux requires explicit linking with the POSIX thread library during compilation.
- **Solution:** Add the `-lpthread` flag to the compiler command or Makefile:
  ```bash
  g++ shadow_thread.cpp -o shadow_thread -lpthread
